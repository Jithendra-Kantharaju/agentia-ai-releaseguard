# Third-party data

## LogChunks

`mock_data/real_failure/` contains one real failed Travis CI build log taken from the LogChunks data set, and the
evaluation in `eval/` was computed on it.

- Title: LogChunks: A Data Set for Build Log Analysis
- Authors: Brandt et al. (Delft University of Technology)
- Source: https://zenodo.org/records/3632351
- License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
- Changes: log text was normalised (line endings, ANSI colour codes removed). Nothing else was altered.

The full data set is not included in this repository. Download it from the link above.
