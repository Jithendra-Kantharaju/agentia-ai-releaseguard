##### agentia cicd work set --help
Set the active work item and prepare a local feature branch. Calls the CICD gateway work/set endpoint, requires a clean tracked working tree, fetches the work item base branch from origin, fetches the feature branch when it exists on origin, then creates or checks out feature/<user-story-name> from the remote feature branch when present, otherwise from the base branch. A gateway warning prints the message, skips git, clears lastBaseBranch/lastDevOrgBranch/lastPullRequestBaseUrl, and records lastWorkItemId/lastWorkItem/lastWorkItemTitle from the returned work item. After work/set returns, compares the Story source credential with the CICD project default: warns when the default or Story credential is missing, and warns without changing the Story when they differ (shows the current credential and environment; use work update to change it). With --none, clears every last* key from `.agentia/config.user.json` and checks out the previous lastBaseBranch when present, else main, else master, else stays put.

USAGE
  $ agentia cicd work set [ID] [--json] [--base-branch <value>] [--none]

ARGUMENTS
  [ID]  User story ID or name (omit with --none)

FLAGS
  --base-branch=<value>  Override the base branch returned by the work/set
                         endpoint
  --none                 Clear every last* key from `.agentia/config.user.json`
                         and check out lastBaseBranch, else main, else master.

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Set the active work item and prepare a local feature branch. Calls the CICD
  gateway work/set endpoint, requires a clean tracked working tree, fetches the
  work item base branch from origin, fetches the feature branch when it exists
  on origin, then creates or checks out feature/<user-story-name> from the
  remote feature branch when present, otherwise from the base branch. A gateway
  warning prints the message, skips git, clears
  lastBaseBranch/lastDevOrgBranch/lastPullRequestBaseUrl, and records
  lastWorkItemId/lastWorkItem/lastWorkItemTitle from the returned work item.
  After work/set returns, compares the Story source credential with the CICD
  project default: warns when the default or Story credential is missing, and
  warns without changing the Story when they differ (shows the current
  credential and environment; use work update to change it). With --none, clears
  every last* key from `.agentia/config.user.json` and checks out the previous
  lastBaseBranch when present, else main, else master, else stays put.

EXAMPLES
  $ agentia cicd work set a0SKC000000CmZ2AU

  $ agentia cicd work set US-0001 --json

  $ agentia cicd work set US-0001 --base-branch develop

  $ agentia cicd work set --none

##### agentia cicd work test --help
Run quality gates for the current work item. With --local (the default) it runs project-root .agentia_quality_gates.sh (macOS/Linux) or .agentia_quality_gates.cmd (Windows) when present. When no project script exists it warns, runs the stock Agentia setup sample from a temporary file, then deletes that file. With --cloud it runs remote Copado quality gates (not implemented yet).

USAGE
  $ agentia cicd work test [--json] [--apex-test-classes <value>] [--cloud]
    [-e <value>...] [--local] [--rerun-failed-apex-tests]

FLAGS
  -e, --env=<value>...             Extra environment variable for the
                                   quality-gate script as NAME=value.
                                   Repeatable. Applied before reserved
                                   AGENTIA_APEX_* variables.
      --apex-test-classes=<value>  Comma-separated Apex test class names passed
                                   to local quality gates as
                                   AGENTIA_APEX_TEST_CLASSES
      --cloud                      Run remote Copado quality gates (not
                                   implemented yet).
      --local                      Run local project-root quality gates scripts.
                                   Used by default when --cloud is omitted.
      --rerun-failed-apex-tests    Pass AGENTIA_APEX_RERUN_FAILED=--rerun-failed
                                   -apex-tests to local quality gates so sample
                                   scripts forward that flag to work test apex.

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Run quality gates for the current work item. With --local (the default) it
  runs project-root .agentia_quality_gates.sh (macOS/Linux) or
  .agentia_quality_gates.cmd (Windows) when present. When no project script
  exists it warns, runs the stock Agentia setup sample from a temporary file,
  then deletes that file. With --cloud it runs remote Copado quality gates (not
  implemented yet).

EXAMPLES
  $ agentia cicd work test

  $ agentia cicd work test --local --apex-test-classes=MyTest,OtherTest

  $ agentia cicd work test --local --rerun-failed-apex-tests

  $ agentia cicd work test -e SKIP_LWC_TESTS=1 -e TOOL_API_KEY=secret

  $ agentia cicd work test --json

  $ agentia cicd work test --cloud

COMMANDS
  cicd work test apex
      Run specified Apex test classes via Salesforce CLI (`sf apex run test`) with
      code coverage. Usually run from project-root local quality gates
      (`.agentia_quality_gates.sh` / `.agentia_quality_gates.cmd`) when those
      scripts are configured. When `--apex-test-classes` is omitted or empty, logs
      that no Apex tests were specified and exits without running Salesforce CLI.
      Failed runs save `.agentia/apex.tests.<user-story>.json`; successful runs
      delete that file. `--rerun-failed-apex-tests` runs the previously failed
      classes (optionally filtered by `--apex-test-classes`). Prints the test-run
      summary when the run passes, or failing tests with their messages and stack
      traces when it fails. Exits with the same process exit code as Salesforce
      CLI (`sf`), including 100 when Apex tests fail.

##### agentia cicd work submit --help
Submit the current feature/<lastWorkItem> work item for pipeline quality gates and validation. Runs project-root .agentia_quality_gates.sh (macOS/Linux) or .agentia_quality_gates.cmd (Windows) when present, pushes and registers commits when the branch is ahead of origin, then calls headless work/submit (Promote Action with validate=true). When the last pending related job template name contains Commit, waits up to 5 minutes for that job before submitting. Before submit or promote, counts user stories ahead and behind between the source environment and the next pipeline environment, and warns when stories behind might cause promotion conflicts (advising `agentia cicd work environment-sync`). After a successful submit or promote, uploads the captured command output as a Salesforce File on the user story (`Local Commit Logs <commitId> <datetime>.txt`) via `/agentia/headless/file/upload`. HTTP 404 is ignored until that endpoint is rolled out; other upload failures are warned and do not fail the command. With --done or --deploy, matches Copado UI Submit when promoting (validate=false / headless work/done). cicd work done is a compatibility alias of this command with --done.

USAGE
  $ agentia cicd work submit [--json] [--skip-nested-metadata-detection]
    [--apex-test-classes <value>] [--deploy] [--done] [--skip-local-tests]
    [--skip-pull-request]

FLAGS
  --apex-test-classes=<value>       Comma-separated Apex test class names passed
                                    to local quality gates as
                                    AGENTIA_APEX_TEST_CLASSES
  --deploy                          Alias of --done: promote instead of
                                    validate-only (Copado UI Submit promote)
  --done                            Promote instead of validate-only (Copado UI
                                    Submit promote); honors
                                    --skip-nested-metadata-detection. --deploy
                                    is an alias of --done.
  --skip-local-tests                Skip running local quality gates scripts in
                                    the project root
  --skip-nested-metadata-detection  Do not detect the nested metadata changed
                                    across the branch when pushing (also
                                    configurable via skipNestedMetadataDetection
                                    in .agentia/config.json or
                                    .agentia/config.user.json)
  --skip-pull-request               Do not open the pull request compare URL
                                    after submit (also configurable via
                                    skipPullRequest in .agentia/config.json or
                                    .agentia/config.user.json)

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Submit the current feature/<lastWorkItem> work item for pipeline quality gates
  and validation. Runs project-root .agentia_quality_gates.sh (macOS/Linux) or
  .agentia_quality_gates.cmd (Windows) when present, pushes and registers
  commits when the branch is ahead of origin, then calls headless work/submit
  (Promote Action with validate=true). When the last pending related job
  template name contains Commit, waits up to 5 minutes for that job before
  submitting. Before submit or promote, counts user stories ahead and behind
  between the source environment and the next pipeline environment, and warns
  when stories behind might cause promotion conflicts (advising `agentia cicd
  work environment-sync`). After a successful submit or promote, uploads the
  captured command output as a Salesforce File on the user story (`Local Commit
  Logs <commitId> <datetime>.txt`) via `/agentia/headless/file/upload`. HTTP 404
  is ignored until that endpoint is rolled out; other upload failures are warned
  and do not fail the command. With --done or --deploy, matches Copado UI Submit
  when promoting (validate=false / headless work/done). cicd work done is a
  compatibility alias of this command with --done.

EXAMPLES
  $ agentia cicd work submit

  $ agentia cicd work submit --apex-test-classes=MyTest,OtherTest

  $ agentia cicd work submit --skip-local-tests

  $ agentia cicd work submit --skip-pull-request

  $ agentia cicd work submit --done

  $ agentia cicd work submit --deploy

  $ agentia cicd work submit --done --skip-nested-metadata-detection

  $ agentia cicd work submit --json
